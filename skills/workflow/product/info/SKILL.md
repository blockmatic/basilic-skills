## Purpose

Propose file and documentation moves. Durable information architecture belongs in existing MDX. Do not invent a second sitemap.

## Steps

1. Inspect current folders, nav, and the file-organization contract.
2. Propose the smallest move list with from/to paths. Group 2+ related files; drop folder-name prefixes inside groups.
3. Save only if the user gave a path. Do not move files unless they also asked to implement.

## Verification

- [ ] Each move has a reason tied to existing conventions.
- [ ] No parallel documentation hierarchy was created.

## Handoff

Return the move list and whether `/build` is authorized.
