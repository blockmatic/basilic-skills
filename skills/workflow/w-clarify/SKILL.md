Ask only for decisions that block correct work. Stay inside the request. Do not invent product scope. A relentless design-tree interview is [grill](../w-grill/SKILL.md). Fog bigger than one session is [wayfinder](../w-wayfinder/SKILL.md).

1. Inspect code, README, and matching MDX/ADRs for answers that already exist.
2. List remaining consequential gaps (behavior, trust boundary, destructive ops). Skip reversible details.
3. Ask the smallest set of questions. Continue with stated assumptions when the user already covered them.
