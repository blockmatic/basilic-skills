# Grill round format

Ask the whole frontier in one round. Number each question and give a recommended answer. Wait for the user's answers before the next round.

```
**Q1** - **<title>**: <body, including choices when the decision branches>

Recommended: <answer>

---

**Q2** - **<title>**: <body>

Recommended: <answer>
```

A question whose answer depends on another question still open in this round belongs to a later round.
